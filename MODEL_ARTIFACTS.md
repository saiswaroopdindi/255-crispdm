Each methodology folder contains a `.joblib` model artifact and a CSV scoring output generated by its notebook.

| Folder | Model artifact | Scoring output |
|---|---|---|
| `01_crisp_dm_bike_demand` | `bike_demand_calendar_model.joblib` | `bike_demand_q4_sample_scoring.csv` (first 100 holdout rows) |
| `02_semma_wine_quality` | `wine_quality_model.joblib` | `wine_quality_sample_scoring.csv` (first 20 test rows) |
| `03_kdd_wholesale_segments` | `wholesale_exploratory_snapshot.joblib` | `wholesale_exploratory_cluster_assignments.csv` (440 rows) |

Rebuild artifacts by running each notebook from top to bottom. Model objects use Python pickle serialization through joblib; only load artifacts from this project or another trusted source. Recreate them under a compatible Python and scikit-learn version if loading fails. The notebooks are the canonical, inspectable implementation.
